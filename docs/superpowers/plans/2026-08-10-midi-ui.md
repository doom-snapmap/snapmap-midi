# snapmap-midi Control UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `audition` workflow with a pywebview control window that lets a user set the instrument for every MIDI channel, remap drum keys, tune the concurrency levers, and see the compile result before exporting `rawmap.json`.

**Architecture:** A pywebview window over the existing library. Python keeps every decision; JavaScript renders and calls `window.pywebview.api`. Three new library capabilities — MIDI channel analysis, per-channel mute, per-drum-key remap — plus a settings document shared by the GUI and the CLI. No server and no sockets: `tests/test_document.py:294` bans network clients from shipped modules and that constraint stands.

**Tech Stack:** Python 3.12, mido, pywebview 5 (Windows-only dependency), hand-written HTML/CSS/JS with no framework and no bundler.

```python
def _write_midi(tmp_path, events):
    """A one-track file. `events` is [(channel, program or None, pitch)]."""
    import mido

    mid = mido.MidiFile()
    track = mido.MidiTrack()
    mid.tracks.append(track)
    for channel, program, pitch in events:
        if program is not None:
            track.append(mido.Message("program_change", channel=channel, program=program, time=0))
        track.append(mido.Message("note_on", channel=channel, note=pitch, velocity=64, time=0))
        track.append(mido.Message("note_off", channel=channel, note=pitch, velocity=0, time=240))
    path = tmp_path / "probe.mid"
    mid.save(str(path))
    return path
```

```python
@lru_cache(maxsize=1)
def _gm_names() -> dict:
    """The General MIDI name tables, read once.

    Shipped as data rather than written inline because 128 names in a source
    file is a wall nobody reads, and the numbers are a published specification
    rather than a judgement call like the tables above.
    """
    path = Path(__file__).resolve().parents[1] / "data" / "gm_programs.json"
    return json.loads(path.read_text(encoding="utf-8"))


def gm_program_name(program: int) -> str:
    """The General MIDI name for a program number.

    Raises IndexError past 127 rather than clamping: a program number out of
    range means the caller has a bug, and naming it "Gunshot" hides that.
    """
    names = _gm_names()["programs"]
    if not 0 <= program < len(names):
        raise IndexError("no General MIDI program %r" % program)
    return names[program]


def gm_drum_name(key: int) -> str:
    """The General MIDI percussion name for a key, or the bare key number.

    Unlike programs, percussion keys outside the standard set are ordinary --
    files use them, and the picker shows them so they can be mapped by hand.
    """
    return _gm_names()["percussion"].get(str(key), "Key %d" % key)
```

```python
"""What a MIDI file contains, named in the user's terms rather than the compiler's.

`parse_notes` cannot answer this. By the time it returns, a program number has
already become a family and the channel's own identity -- which instrument the
composer asked for -- is gone. Choosing an instrument per channel needs the
question asked before that collapse, so this reads the file separately.

It is deliberately cheap: message counts and pitch extremes, no note pairing,
no palette lookups. The window calls it once per file.
"""

from __future__ import annotations

from dataclasses import dataclass, field
from typing import Optional

from snapmap_midi.music.gm import (
    DRUM_CHANNEL,
    DRUM_MAP,
    channel_is_percussion_source,
    gm_program_name,
    gm_to_family,
)


@dataclass
class ChannelInfo:
    channel: int
    program: int
    program_name: str
    notes: int
    lowest: Optional[int]
    highest: Optional[int]
    is_drums: bool
    auto_family: Optional[str]
    drum_keys: dict = field(default_factory=dict)


@dataclass
class MidiAnalysis:
    path: str
    duration_s: float
    drums_detected: bool
    channels: list = field(default_factory=list)


def analyze(mid_path) -> MidiAnalysis:
    """Inspect a MIDI file: which channels play, what they asked for, how high.

    The program recorded for a channel is the one in force at its FIRST note,
    not the last program change on that channel. A file that switches
    instruments mid-channel is rare; showing the opening instrument matches
    what a listener hears first and what the compiler's own lookup does for the
    majority of the notes.
    """
    import mido

    mid = mido.MidiFile(str(mid_path), clip=True)
    drums_on = channel_is_percussion(mid)

    program: dict = {}
    seen: dict = {}
    elapsed = 0.0
    for msg in mid:
        elapsed += msg.time
        if msg.type == "program_change":
            program[msg.channel] = msg.program
        elif msg.type == "note_on" and msg.velocity > 0:
            entry = seen.setdefault(
                msg.channel,
                {"program": program.get(msg.channel, 0), "notes": 0, "keys": {}},
            )
            entry["notes"] += 1
            entry["keys"][msg.note] = entry["keys"].get(msg.note, 0) + 1

    channels = []
    for channel in sorted(seen):
        entry = seen[channel]
        keys = entry["keys"]
        is_drums = channel == DRUM_CHANNEL and drums_on
        channels.append(
            ChannelInfo(
                channel=channel,
                program=entry["program"],
                program_name=gm_program_name(entry["program"]),
                notes=entry["notes"],
                lowest=min(keys),
                highest=max(keys),
                is_drums=is_drums,
                auto_family=None if is_drums else gm_to_family(entry["program"]),
                drum_keys={k: DRUM_MAP.get(k) for k in sorted(keys)} if is_drums else {},
            )
        )

    return MidiAnalysis(
        path=str(mid_path),
        duration_s=round(elapsed, 2),
        drums_detected=drums_on,
        channels=channels,
    )


def as_dict(analysis: MidiAnalysis) -> dict:
    """The analysis as plain JSON types, for the bridge.

    Dataclasses do not survive the trip to Javascript, and `asdict` would give
    integer dictionary keys that JSON cannot express -- `drum_keys` is keyed by
    MIDI key number, so those become strings here and are read back as ints on
    the way in.
    """
    return {
        "path": analysis.path,
        "duration_s": analysis.duration_s,
        "drums_detected": analysis.drums_detected,
        "channels": [
            {
                "channel": c.channel,
                "program": c.program,
                "program_name": c.program_name,
                "notes": c.notes,
                "lowest": c.lowest,
                "highest": c.highest,
                "is_drums": c.is_drums,
                "auto_family": c.auto_family,
                "drum_keys": {str(k): v for k, v in c.drum_keys.items()},
            }
            for c in analysis.channels
        ],
    }
```

```python
#: Curated ear-labels, alongside the palette itself.
_LABELS = Path(__file__).resolve().parents[1] / "data" / "soundfont_labels.json"


def pitched_families() -> list:
    """Every category that can play a pitch, in declaration order.

    A category whose sound names encode no note produces nothing from
    `build_note_index`, so `decl_for` returns None for it and every note
    assigned there is dropped. Offering such a category in a picker would look
    exactly like it worked and produce a silent map, so the list is derived
    from the index rather than written down.
    """
    index = build_note_index()
    return [c for c in categories() if index.get(c)]


def family_range(family: str) -> Optional[tuple]:
    """The lowest and highest MIDI note a family can play, or None.

    `decl_for` never fails outside this range -- it octave-displaces instead --
    so the range is not a limit so much as the boundary past which a melody
    stops being the melody that was written.
    """
    available = build_note_index().get(family)
    return (min(available), max(available)) if available else None


def unpitched_categories() -> list:
    """Every category with no pitched sounds, in declaration order.

    These are the drum and effect banks: the pool a percussion key may be
    remapped into.
    """
    index = build_note_index()
    return [c for c in categories() if not index.get(c)]


@lru_cache(maxsize=1)
def sound_labels() -> dict:
    """Curated ear-labels per sound, as {category: {sound: {...}}}.

    Recorded by listening and shipped since the first release, read by no code
    until the drum picker. Coverage is partial by nature -- someone sat and
    listened to `ins_noise` -- so every caller must treat a missing entry as
    ordinary rather than as an error.
    """
    try:
        payload = json.loads(_LABELS.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        # Absent or unreadable labels cost a hint, not a compile.
        return {}
    return {k: v for k, v in payload.items() if not k.startswith("_")}
```

```python
"""The settings document: one schema the window writes and the command line reads.

Tuning a song is work -- sixteen channels, a drum kit, and half a dozen levers
that trade fidelity against the engine's emitter-slot limit. Without a file,
closing the window throws that away and the only way to repeat a result is to
redo it by hand.

Unknown keys are an error rather than a silent no-op. A settings file is meant
to be hand-editable, and a typo that leaves the setting it was meant to change
sitting at its default is the same quiet wrong answer the retired `--out` flag
produced.
"""

from __future__ import annotations

import json
from pathlib import Path

from snapmap_midi.sound import palette

#: Bumped when a document written by an older version cannot be read as-is.
SETTINGS_VERSION = 1

_TUNING_DEFAULTS = {
    "max_speakers": 32,
    "release_s": 0.1,
    "hard_stop": False,
    "max_events": None,
    "max_poly": None,
    "cap_sustain_ms": None,
    "bass_cap_ms": None,
}

_DRUM_CHOICES = ("auto", "on", "off")


class SettingsError(ValueError):
    """A settings document that cannot be honoured as written."""


def defaults(midi=None) -> dict:
    """A complete document with nothing chosen yet."""
    return {
        "version": SETTINGS_VERSION,
        "midi": str(midi) if midi else None,
        "button": "snapmap-midi-song",
        "out_dir": None,
        "baseline": None,
        "channels": {},
        "drums": "auto",
        "drum_keys": {},
        "tuning": dict(_TUNING_DEFAULTS),
    }


def merge(base: dict, patch: dict) -> dict:
    """A patch applied over a document, one level into channels and tuning.

    A patch names only what changed. Replacing whole sections instead would
    make "mute channel 1" clear channel 1's instrument, because the window
    sends the field that moved and not the ones that did not.
    """
    merged = {k: (dict(v) if isinstance(v, dict) else v) for k, v in base.items()}
    for key, value in patch.items():
        if key == "channels":
            channels = {k: dict(v) for k, v in merged.get("channels", {}).items()}
            for channel, fields in (value or {}).items():
                channels.setdefault(str(channel), {"family": None, "muted": False})
                channels[str(channel)].update(fields)
            merged["channels"] = channels
        elif key in ("tuning", "drum_keys"):
            section = dict(merged.get(key) or {})
            section.update(value or {})
            merged[key] = section
        else:
            merged[key] = value
    return merged


def validate(doc: dict) -> dict:
    """A normalized copy, or SettingsError naming what is wrong.

    Every message names the offending key or value, because the reader may be
    looking at a file they wrote in a text editor with no window open.
    """
    template = defaults()
    unknown = set(doc) - set(template)
    if unknown:
        raise SettingsError("unknown setting(s): %s" % ", ".join(sorted(unknown)))

    version = doc.get("version", SETTINGS_VERSION)
    if version != SETTINGS_VERSION:
        raise SettingsError(
            "settings version %r; this build reads version %d" % (version, SETTINGS_VERSION)
        )

    out = dict(template)
    out.update({k: v for k, v in doc.items() if k not in ("channels", "drum_keys", "tuning")})

    if out["drums"] not in _DRUM_CHOICES:
        raise SettingsError("drums must be one of %s" % ", ".join(_DRUM_CHOICES))

    pitched = set(palette.pitched_families())
    channels = {}
    for channel, fields in (doc.get("channels") or {}).items():
        key = _channel_key(channel)
        extra = set(fields) - {"family", "muted"}
        if extra:
            raise SettingsError("unknown channel setting(s): %s" % ", ".join(sorted(extra)))
        family = fields.get("family")
        if family is not None and family not in pitched:
            raise SettingsError(
                "%r cannot play a pitch, so every note on channel %d would be "
                "dropped; choose one of: %s" % (family, key, ", ".join(sorted(pitched)))
            )
        channels[str(key)] = {"family": family, "muted": bool(fields.get("muted", False))}
    out["channels"] = channels

    unpitched = {s for c in palette.unpitched_categories() for s in palette.sounds_in_category(c)}
    drum_keys = {}
    for key, sound in (doc.get("drum_keys") or {}).items():
        number = _drum_key(key)
        if sound not in unpitched:
            raise SettingsError(
                "%r is not an unpitched sound, so it would play one fixed note "
                "under every hit on key %d" % (sound, number)
            )
        drum_keys[str(number)] = sound
    out["drum_keys"] = drum_keys

    tuning = dict(_TUNING_DEFAULTS)
    supplied = doc.get("tuning") or {}
    unknown = set(supplied) - set(_TUNING_DEFAULTS)
    if unknown:
        raise SettingsError("unknown tuning lever(s): %s" % ", ".join(sorted(unknown)))
    tuning.update(supplied)
    _check_tuning(tuning)
    out["tuning"] = tuning

    return out


def to_compile_kwargs(doc: dict) -> dict:
    """The document as keyword arguments for `compile_to_rawmap`.

    JSON keys are strings and `channel_families` is keyed by MIDI channel
    number, so a string key there matches nothing and silently changes no
    instrument at all.
    """
    doc = validate(doc)
    channels = doc["channels"]
    return {
        "button_name": doc["button"],
        "channel_families": {
            int(c): f["family"] for c, f in channels.items() if f["family"] is not None
        },
        "channel_mutes": {int(c) for c, f in channels.items() if f["muted"]},
        "drums": {"auto": "auto", "on": True, "off": False}[doc["drums"]],
        "drum_key_overrides": {int(k): v for k, v in doc["drum_keys"].items()},
        "max_speakers": doc["tuning"]["max_speakers"],
        "release_s": doc["tuning"]["release_s"],
        "hard_stop": doc["tuning"]["hard_stop"],
        "max_events": doc["tuning"]["max_events"],
        "max_poly": doc["tuning"]["max_poly"],
        "cap_sustain_ms": doc["tuning"]["cap_sustain_ms"],
        "bass_cap_ms": doc["tuning"]["bass_cap_ms"],
    }


def load(path) -> dict:
    """Read and validate a settings file."""
    try:
        payload = json.loads(Path(path).read_text(encoding="utf-8"))
    except OSError as exc:
        raise SettingsError("could not read settings at %s (%s)" % (path, exc)) from exc
    except ValueError as exc:
        raise SettingsError("%s is not valid JSON (%s)" % (path, exc)) from exc
    return validate(payload)


def save(doc: dict, path) -> None:
    """Write a settings file, indented, for a human to open and edit."""
    text = json.dumps(validate(doc), indent=2, ensure_ascii=False) + "\n"
    Path(path).write_text(text, encoding="utf-8")


def _channel_key(value) -> int:
    try:
        number = int(value)
    except (TypeError, ValueError):
        raise SettingsError("channel %r is not a number" % value) from None
    if not 0 <= number <= 15:
        raise SettingsError("channel %d is outside MIDI's 0-15" % number)
    return number


def _drum_key(value) -> int:
    try:
        number = int(value)
    except (TypeError, ValueError):
        raise SettingsError("drum key %r is not a number" % value) from None
    if not 0 <= number <= 127:
        raise SettingsError("drum key %d is outside MIDI's 0-127" % number)
    return number


def _check_tuning(tuning: dict) -> None:
    if not isinstance(tuning["max_speakers"], int) or tuning["max_speakers"] < 1:
        raise SettingsError("max_speakers must be a positive whole number")
    if not isinstance(tuning["release_s"], (int, float)) or tuning["release_s"] < 0:
        raise SettingsError("release_s must be zero or more seconds")
    if not isinstance(tuning["hard_stop"], bool):
        raise SettingsError("hard_stop is on or off")
    for lever in ("max_events", "max_poly", "cap_sustain_ms", "bass_cap_ms"):
        value = tuning[lever]
        if value is not None and (not isinstance(value, int) or value < 1):
            raise SettingsError("%s is unset, or a positive whole number" % lever)
```

```python
"""One window's state: the file it is looking at, and the choices made about it.

Bridge calls arrive on separate threads, so every mutation takes the lock. The
parsed analysis is kept because it costs a file read and never changes once the
file is chosen; the compile is not, because it is what every change re-runs.
"""

from __future__ import annotations

import threading
from pathlib import Path
from typing import Optional

from snapmap_midi import paths, settings as settings_module
from snapmap_midi.compile import compile_to_rawmap
from snapmap_midi.music import analysis as analysis_module
from snapmap_midi.sound import palette

#: Above this, the engine's emitter recycling starts cutting sustained notes.
#: Taken from the failure the tuning levers exist for, not measured precisely.
_BUSY_EVENTS = 2000


class Session:
    def __init__(self, midi=None, settings_path=None):
        self._lock = threading.RLock()
        self._analysis = None
        self._settings = settings_module.defaults()
        if settings_path:
            self._settings = settings_module.load(settings_path)
            if self._settings.get("midi"):
                self.load(self._settings["midi"])
        if midi:
            self.load(midi)

    def load(self, midi_path) -> dict:
        """Read a MIDI file and keep its analysis. Returns the analysis dict."""
        path = Path(midi_path)
        if not path.is_file():
            raise FileNotFoundError("no such MIDI file: %s" % midi_path)
        result = analysis_module.analyze(path)
        with self._lock:
            self._analysis = result
            self._settings = settings_module.merge(self._settings, {"midi": str(path)})
        return analysis_module.as_dict(result)

    def analysis_dict(self) -> Optional[dict]:
        with self._lock:
            return analysis_module.as_dict(self._analysis) if self._analysis else None

    def settings(self) -> dict:
        with self._lock:
            return dict(self._settings)

    def apply(self, patch: dict) -> dict:
        """Merge a patch and validate the result. Nothing changes if it fails."""
        with self._lock:
            candidate = settings_module.validate(settings_module.merge(self._settings, patch))
            self._settings = candidate
            return dict(candidate)

    def compile(self):
        """Compile with the current settings. Returns (bytes, stats)."""
        with self._lock:
            doc = dict(self._settings)
            analysis = self._analysis
        if analysis is None:
            raise LookupError("no MIDI file loaded")
        kwargs = settings_module.to_compile_kwargs(doc)
        baseline = Path(doc["baseline"]).read_bytes() if doc["baseline"] else None
        raw, stats = compile_to_rawmap(analysis.path, baseline, **kwargs)
        return raw, stats

    def stats(self) -> dict:
        """A compile whose bytes are thrown away, plus what to warn about."""
        _, stats = self.compile()
        return {**stats, "warnings": self._warnings(stats)}

    def export(self) -> dict:
        """Write the map where the loader reads it."""
        raw, stats = self.compile()
        with self._lock:
            out_dir = self._settings["out_dir"]
        destination = paths.rawmap_destination(out_dir)
        destination.parent.mkdir(parents=True, exist_ok=True)
        destination.write_bytes(raw)
        return {
            "destination": str(destination),
            "advice": _advice(destination),
            "stats": {**stats, "warnings": self._warnings(stats)},
        }

    def _warnings(self, stats) -> list:
        """Plain-language problems, in the order they cost the listener most."""
        with self._lock:
            doc = dict(self._settings)
            analysis = self._analysis
        out = []
        if not stats["notes"]:
            out.append("This map is silent. Nothing will play when you press the switch.")
        if stats["dropped"]:
            out.append(
                "%d note(s) have no sound in the palette and were dropped."
                % stats["dropped"]
            )
        for channel in analysis.channels if analysis else []:
            chosen = (doc["channels"].get(str(channel.channel)) or {}).get("family")
            family = chosen or channel.auto_family
            if channel.is_drums or not family or channel.lowest is None:
                continue
            span = palette.family_range(family)
            if span is None:
                continue
            low, high = span
            if channel.lowest < low or channel.highest > high:
                out.append(
                    "Channel %d reaches %d-%d but %s plays %d-%d, so notes outside "
                    "that jump an octave." % (channel.channel, channel.lowest,
                                              channel.highest, family, low, high)
                )
        if stats["events"] > _BUSY_EVENTS:
            out.append(
                "%d events is dense. The engine recycles sound slots under load, and a "
                "note whose slot is recycled plays to the end of its sample. Lower the "
                "polyphony cap or mute a channel." % stats["events"]
            )
        return out


def _advice(destination) -> str:
    """The same three cases the command line reports, in one string.

    Landing somewhere the loader does not read is NOT "it worked", and saying
    so was the quiet wrong answer the retired `--out` flag produced.
    """
    if paths.destination_is_loadable(destination):
        return "Load it with `sh_rawmaps_on` in the console, then open any map."
    if paths.loader_dir() is None:
        return (
            "There is no loader folder on this platform. Copy it to the game "
            "machine's %%LOCALAPPDATA%%\\%s\\%s to play it."
            % (paths.LOADER_DIR_NAME, paths.RAWMAP_NAME)
        )
    return "The loader only reads %s. Move it there to play it." % paths.rawmap_destination()
```

```python
"""The bridge: the only surface Javascript can reach.

Every method returns a result rather than raising. An exception crossing this
boundary reaches Javascript as an opaque Error with no message worth showing,
so the window would have nothing to put in front of the user.

Nothing here imports pywebview. The window hands itself over with `attach`
once it exists, and the file dialogs are the only methods that need it.
"""

from __future__ import annotations

from snapmap_midi import settings as settings_module
from snapmap_midi.music.gm import gm_drum_name
from snapmap_midi.sound import palette
from snapmap_midi.ui.session import Session

_MIDI_TYPES = ("MIDI files (*.mid;*.midi)", "All files (*.*)")
_JSON_TYPES = ("Settings files (*.json)", "All files (*.*)")


def _ok(**payload) -> dict:
    return {"ok": True, **payload}


def _fail(message) -> dict:
    return {"ok": False, "error": str(message)}


class Bridge:
    """Javascript calls these as `window.pywebview.api.<name>(...)`."""

    def __init__(self, midi=None, settings_path=None):
        self._window = None
        try:
            self._session = Session(midi=midi, settings_path=settings_path)
            self._error = None
        except Exception as exc:  # a bad file on the command line must still open
            self._session = Session()
            self._error = str(exc)

    def attach(self, window) -> None:
        """Hand the bridge the window, once pywebview has made one."""
        self._window = window

    def startup(self) -> dict:
        """Everything the window needs on first paint, in one call."""
        return _ok(
            settings=self._session.settings(),
            analysis=self._session.analysis_dict(),
            catalog=self.catalog(),
            error=self._error,
        )

    def pick_midi(self) -> dict:
        path = self._open_dialog(_MIDI_TYPES)
        return self.load_midi(path) if path else _fail("no file chosen")

    def load_midi(self, path: str) -> dict:
        try:
            analysis = self._session.load(path)
        except FileNotFoundError as exc:
            return _fail(exc)
        except Exception as exc:
            return _fail("%s could not be read as a MIDI file (%s)" % (path, exc))
        return _ok(analysis=analysis, settings=self._session.settings(), **self._stats_payload())

    def catalog(self) -> dict:
        """Every choice the window can offer, resolved once."""
        labels = palette.sound_labels()
        families = []
        for name in palette.pitched_families():
            span = palette.family_range(name)
            families.append(
                {
                    "name": name,
                    "lowest": span[0],
                    "highest": span[1],
                    "sounds": len(palette.sounds_in_category(name)),
                }
            )
        drum_sounds = []
        for category in palette.unpitched_categories():
            for sound in palette.sounds_in_category(category):
                entry = labels.get(category, {}).get(sound) or {}
                drum_sounds.append(
                    {
                        "name": sound,
                        "category": category,
                        "label": entry.get("heard") or entry.get("role") or "",
                    }
                )
        return _ok(families=families, drum_sounds=drum_sounds, drum_names=_drum_names())

    def get_settings(self) -> dict:
        return _ok(settings=self._session.settings())

    def apply_settings(self, patch: dict) -> dict:
        try:
            updated = self._session.apply(patch or {})
        except settings_module.SettingsError as exc:
            return _fail(exc)
        return _ok(settings=updated, **self._stats_payload())

    def dry_run(self) -> dict:
        try:
            return _ok(stats=self._session.stats())
        except LookupError:
            return _fail("no MIDI file loaded yet")
        except Exception as exc:
            return _fail(exc)

    def pick_out_dir(self) -> dict:
        path = self._folder_dialog()
        if not path:
            return _fail("no folder chosen")
        return self.apply_settings({"out_dir": path})

    def export(self) -> dict:
        try:
            return _ok(**self._session.export())
        except LookupError:
            return _fail("no MIDI file loaded yet")
        except OSError as exc:
            return _fail("could not write the map (%s)" % exc)
        except Exception as exc:
            return _fail(exc)

    def save_settings_file(self) -> dict:
        path = self._save_dialog()
        if not path:
            return _fail("no file chosen")
        try:
            settings_module.save(self._session.settings(), path)
        except (OSError, settings_module.SettingsError) as exc:
            return _fail(exc)
        return _ok(path=str(path))

    def load_settings_file(self) -> dict:
        path = self._open_dialog(_JSON_TYPES)
        if not path:
            return _fail("no file chosen")
        try:
            doc = settings_module.load(path)
        except settings_module.SettingsError as exc:
            return _fail(exc)
        result = self.apply_settings(doc)
        if result["ok"] and doc.get("midi"):
            return self.load_midi(doc["midi"])
        return result

    def _stats_payload(self) -> dict:
        try:
            return {"stats": self._session.stats()}
        except Exception:
            # A settings change that cannot compile is still a settings change.
            return {"stats": None}

    def _open_dialog(self, file_types):
        if self._window is None:
            return None
        import webview

        chosen = self._window.create_file_dialog(
            webview.FileDialog.OPEN, allow_multiple=False, file_types=file_types
        )
        return chosen[0] if chosen else None

    def _folder_dialog(self):
        if self._window is None:
            return None
        import webview

        chosen = self._window.create_file_dialog(webview.FileDialog.FOLDER)
        return chosen[0] if chosen else None

    def _save_dialog(self):
        if self._window is None:
            return None
        import webview

        return self._window.create_file_dialog(
            webview.FileDialog.SAVE, save_filename="snapmap-midi-settings.json"
        )


def _drum_names() -> dict:
    """General MIDI percussion names, for every key a file might use."""
    return {str(key): gm_drum_name(key) for key in range(128)}
```

Note the guard in `_open_dialog`, `_folder_dialog` and `_save_dialog`: with no window attached they return `None`, and the caller turns that into `ok: False`. That is what makes `test_the_file_dialogs_report_cleanly_with_no_window_attached` pass with pywebview absent — the `import webview` line is never reached.

**Design direction.** This is a sibling of snapmap-plus, so it inherits that tool's shell and token system rather than inventing a second identity: a menubar with the wordmark and a light/dark toggle, a tab strip, panel cards at 8px radius, Segoe UI at 11px, Consolas at 11.5px for data, and a status bar. The boldness goes in one place: **the pitch ruler.** Every channel row plots its notes against a shared MIDI-note axis spanning 21–108, with C-octave gridlines labelled C1 through C8 once at the bottom of the panel. Two bars share that axis per row: the channel's own note span drawn solid in `--accent`, and the selected instrument's playable span drawn behind it as a hatched track. Where the channel's span extends past the instrument's, that overhang is filled with `--sqWarn`. The fit is legible at a glance, without reading a number. This encodes the one fact this tool now knows and audition never told anyone, so it is information rather than decoration.

Motion is one moment only: when the instrument dropdown changes, the instrument track animates to its new position over 180ms so the fit visibly changes. Everything else is static. Wrap it in `@media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }`.

Do not add: numbered section markers, gradient accents, a hero band, or a second accent colour. The palette is snapmap-plus's, plus `--sqWarn` used for overhang and nothing else.

- [ ] **Step 3: Write `app.js`**

Plain ES5-style JavaScript, no framework, no build step, matching snapmap-plus's idiom (`var`, `function`, `document.getElementById`). Structure:

```javascript
var STATE = { settings:null, analysis:null, catalog:null, stats:null };
var LOW = 21, HIGH = 108;            // the ruler's span, piano range

function api(){ return window.pywebview.api; }

window.addEventListener('pywebviewready', function(){
  api().startup().then(function(r){
    STATE.catalog = r.catalog;
    STATE.settings = r.settings;
    STATE.analysis = r.analysis;
    renderAll();
  });
});

function patch(p){                    // every change goes through one path
  return api().apply_settings(p).then(function(r){
    if(!r.ok){ toast(r.error, 'error'); return; }
    STATE.settings = r.settings;
    STATE.stats = r.stats;
    renderAll();
  });
}
```

`renderChannels()` builds one row per `STATE.analysis.channels` entry: channel number, `program_name`, `notes`, the range as `mono` text, a `<select>` of `STATE.catalog.families`, a mute checkbox, and the ruler. The drum channel shows "Drums tab" in place of the dropdown. `renderRuler(row, channel)` positions the three bars by the percentage formula above, computing the overhang segments from the channel's span against the selected family's `lowest`/`highest`.

`renderDrums()` builds one row per key in `analysis.channels[drums].drum_keys`: the key number, `catalog.drum_names[key]`, the current sound, and a `<select>` of `catalog.drum_sounds` showing `name` with `label` as the option's title. A key whose value is `null` is listed under a "Not mapped — these are dropped" heading.

`renderTuning()` builds labelled inputs for the seven levers with a one-line note each on what it costs. `renderExport()` holds the button name field, the output folder with a **Choose folder** button, **Save settings** / **Load settings**, and **Export map**.

`renderStatus()` writes notes, dropped, sustained, voices and events into the status bar, and lists `stats.warnings` beneath the active panel.

Debounce text and number inputs by 250ms before calling `patch`; dropdowns and checkboxes fire immediately.
